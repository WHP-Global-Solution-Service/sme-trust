## คำอธิบายผลประเมิน (Explainability)

ทุกโปรไฟล์ผ่านการตรวจว่าผลประเมินอธิบายได้ครบ: ข้อมูลที่ใช้ (ปัจจัยของทุกมิติที่มีข้อมูล) · แหล่งข้อมูล (`source` ของทุกปัจจัย) · น้ำหนัก (ตั้งค่า + หลังกระจายใหม่ + เลขชุดน้ำหนัก) · ความเสี่ยง (ปัจจัยหักคะแนนพร้อมหลักฐาน) · ข้อมูลที่ไม่เพียงพอ (`insufficientReasons`) · เหตุผลที่ Confidence ลด · เหตุผลของ Band (`bandCapReasons` เมื่อถูกจำกัดที่ B) · เหตุผลที่ขอหรือขอ Badge ไม่ได้ (`recommendation.reasons`)

## ข้อจำกัด

- ค่าน้ำหนัก เกณฑ์ และการหักคะแนนทั้งหมดเป็นค่าสมมติ — ต้องปรับเทียบกับข้อมูลจริงและผ่านการพิจารณาด้านกฎหมาย/ความเป็นธรรมก่อนใช้งานจริง
- โปรไฟล์สร้างจาก Generator และการปรับข้อมูลแบบกำหนดเอง ไม่ใช่ข้อมูลร้านจริง
- กฎเป็น Rule-based ไม่มี Machine Learning — ไม่เรียนรู้จากผลการตัดสินของเจ้าหน้าที่
